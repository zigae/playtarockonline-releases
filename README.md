# PlayTarockOnline – releases

Downloads of the PlayTarockOnline desktop app for Linux (`.deb`, `.rpm`,
`.AppImage`). See [Releases](../../releases).

PlayTarockOnline is the desktop client of https://playtarockonline.com –
Slovenian tarock online for 2, 3 or 4 players.

Also available on Flathub, the Mac App Store and the Microsoft Store.
